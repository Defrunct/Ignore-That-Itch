# Ignore That Itch
Браузерне розширення, яке додає кнопку «Ігнорувати» для ігор та інших товарів на itch.io.

README українською

## Набір функцій
- Позначайте сторінки як «Ігноровані» натисканням однієї кнопки.
- Зміни одразу відображаються на всіх вкладках — не потрібно оновлювати сторінки.
- Додавайте примітки, щоб вказати, чому саме сторінка ігнорується.
- Експорт, імпорт та об’єднання списку ігнорованого в налаштуваннях розширення.
  - Експорт дозволяє зберегти список у файл. Корисно для створення резервної копії або перенесення списку ігнорованого на інший пристрій.
  - Імпорт дозволяє завантажити список з файлу. Це **видалить** наявний список.
  - Об’єднання, на відміну від імпорту, **зберігає** наявний список і додає до нього відсутні елементи з файлу. Також копіює примітки з файлу елементам, які їх не мають.

## Встановлення
### Firefox
1. Відкрийте [сторінку розширення](https://addons.mozilla.org/addon/ignore-that-itch/) в крамниці розширень Firefox.
2. Натисніть «Додати до Firefox».
3. У діалоговому вікні натисніть «Додати».
> [!NOTE]
> Ви також можете обрати «Дозволити розширенню виконуватися в приватних вікнах», щоб Ignore That Itch продовжувало працювати й там.

### Google Chrome та інші браузери
1. Завантажте [архів][latest-download] із файлами розширення.
2. Розпакуйте його у бажану теку.
3. Відкрийте браузер та перейдіть на сторінку керування розширеннями (`chrome://extensions/`).
4. Увімкніть «Режим розробника».
5. Натисніть «Завантажити розпаковане розширення».
6. Оберіть теку з файлами Ignore That Itch (у ній повинен бути файл `manifest.json`).
> [!IMPORTANT]
> Не вимикайте «Режим розробника», інакше розширення не працюватиме.

> [!NOTE]
> Щоб користуватися Ignore That Itch у режимі інкогніто, відкрийте «Деталі» та ввімкніть «Дозволити в анонімному режимі».

## Оновлення
Версія для Firefox оновлюється автоматично.

Для інших браузерів порядок оновлення наступний:
1. Завантажте [архів][latest-download] із файлами розширення.
2. Відкрийте теку, в яку встановили розширення раніше.
3. Замініть файли з цієї теки на файли з архіву.
4. Перезапустіть браузер.\
   Або відкрийте сторінку керування розширеннями (`chrome://extensions/`) та натисніть «Оновити».
> [!IMPORTANT]
> Перед оновленням варто створити резервну копію списку ігнорованого. Для цього натисніть кнопку «Експорт» у налаштуваннях розширення.

> [!NOTE]
> Ви можете підписатися на релізи в цьому репозиторії, щоб отримувати сповіщення про вихід нових версій розширення.

### Чому версія для Chrome не оновлюється автоматично?
Google вимагає $5, щоб зареєструвати акаунт розробника в їхній крамниці.

Я не користуюся Chrome. І вважаю, що вимагати плату за публікацію (безкоштовних) розширень, які додають функціонал та покращують зручність користування браузером, — це антикористувацька практика.

Тому наразі встановити Ignore That Itch у Chrome та інші Chromium-based браузери можна лише за допомогою «Режиму розробника».

Однак, якщо попит на розширення буде достатньо високим, я перегляну можливість його публікації у крамниці розширень Chrome.
